# Phase 0 Evidence Pack

Sanitized evidence for the Phase 0 integration risk spike (`docs/Phase_0_Integration_Risk_Spike_Checklist.md`).

Rules for anything placed here:

- Never include credentials, tokens, cookies, channel secrets, OAuth material, or email bodies.
- Personal email addresses stay out of this directory and out of all committed docs; account identities are referred to by alias (`controlled-01`, `owner`).
- Screenshots must be reviewed for secrets in URLs, headers, and browser tabs before saving.
- Name files `<checklist-section>_<short-slug>.<ext>`, e.g. `s07_gmail_watch_trace.md`.
